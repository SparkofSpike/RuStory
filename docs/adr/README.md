## 状态含义

- **提案（Proposed）**：方向已定，未实现。可以改，但要更新文档。
- **已采纳（Accepted）**：方向已定，实现可有可无。
- **已采纳并实现**：代码里能查到，改动会破坏现有测试。
- **被取代（Superseded）**：不再有效，保留以便追溯。
